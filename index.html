Leo

Chrome extension · built with one teammate

The problem. Most browser work people hate is the same dozen clicks every month — an invoice off a portal, a form, a report. AI browser agents can do it, but they re-think every step on every run: slow, unpredictable, and expensive at any volume.

The hard bit. Websites change. A recording that replays blindly breaks the day a button moves; an agent that reasons through every step never breaks but never gets cheap. The job is getting the reliability of one at the cost of the other.

The call we made. You press record and do the task once. Replay is plain code — no model on a clean run. Each step keeps up to ten ranked selectors — test IDs, labels, text, anchored paths, shadow-DOM chains — so a small redesign usually just falls through to the next one. Only when every selector misses does AI step in: a cheap text-only match first, a vision agent only if that comes back low-confidence. The repaired step is saved back as code, so the next run is deterministic again. For things that change each run, you write an AI step in plain words: “pick last month in the date picker.”

My part. My teammate built the first prototype — the recorder, workflow saving, login, and the first AI step for failed runs. I rebuilt the engine for reliability: trusted input through the Chrome DevTools Protocol, actionability waits, cross-origin iframes, navigation, download and tab handling, hover menus, drag and drop, and per-step run logs with failure screenshots. I also moved every AI call behind authenticated, rate-limited server routes so the extension never holds an API key, and added a provider layer across Anthropic Claude and Groq’s GPT-OSS-120B.

Where it runs. In your own browser, with your existing logins — no handing over passwords, no bot blocking. Passwords and files are never stored; Leo pauses and lets you type them. A web app gives each user an account and syncs workflows across devices.

Where it's going

  1. Gets itself unstuck. Smarter self-repair, and a “show me” mode — when Leo can't do a step, you do it once and it learns it and carries on.
  2. Real workflows. Inputs that change per run, one workflow over a spreadsheet of rows, data pulled off pages into CSV or Google Sheets, loops, conditions, and a secure vault.
  3. Runs without you. Scheduled cloud runs on EU and Asia servers, triggered by API or by assistants like Claude, ChatGPT and Grok. CAPTCHAs and 2FA codes go to you on WhatsApp, Telegram or Teams.
  4. Launch in Asia and Europe. EU hosting and GDPR, a translated interface, a security review, Chrome and Edge store listings, templates for local sites like GST, VAT and SAP — then pricing well under cloud-only agents, because most runs use no AI at all.

Teach your browser a task once, and it keeps doing it — reliably, cheaply, with AI only when something changes.

Venture Flow

AI due diligence for pitch decks

The problem. Early-stage diligence is weeks of a human reading decks, chasing founder names, and writing the same risk memo again. The reading is not the valuable part — the judgement is.

The hard bit. Pitch decks are hostile input: multi-column layouts, five file formats, team slides where the names are images. Getting clean, ordered text out of a PDF exported from Keynote is most of the real work.

The call I made. Reconstruct layout order before the model ever sees the text, run analysis as a background job instead of pretending it's instant, and attach a confidence score to every risk so the output invites disagreement instead of blind trust. Founders are pulled off the team slide for checking against public sources, and follow-up questions run through a chat interface.

02 — Method

Code first, model second

Every AI system I've built ends up the same shape: the model is the smallest box in the diagram. The work is everything around it — getting clean input in, pinning down what has to be exact, and making the output honest about what it doesn't know.

Deterministic where it matters

At Tata Teleservices, IPs, domains, ports and timestamps came out by regex before the model saw anything — so the fields a security team acts on never depended on a summariser getting them right.

AI where things change

Leo replays as plain code and only calls a model when a site has moved. The fix is saved back as code, so the expensive path is taken once, not on every run.

Make uncertainty visible

Venture Flow scores every risk with a confidence. At Tata, summaries were checked by hand against analyst write-ups for missed IPs and hallucinations, not judged on loss alone.
